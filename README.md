# Project Konpeito

## About

Konpeito is a one-stop job management system where you can track your applications as well as browsing available openings from major sites. It is built with Spring Boot backend and React frontend.

## Current features

- Get all applied applications
  - can be organized in page with `page` and `size` parameters
  - can be filtered with `position` and `status` parameters

- Get a specific application with id
- Add application
- Update application
- Delete application

## Plans
